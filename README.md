## ✨ Tecnologias Utilizadas

- 🐍 **Linguagem:** Python 3
- 💻 **Ambiente:** Terminal ou IDEs como VS Code / Thonny
- 🧠 **Conceitos aplicados:** Condicional `if`, operadores lógicos e laços `while`

---

## 🎯 Funcionalidades por Arquivo

### 📄 **estruturas_condicao1.py**

- Verifica a temperatura com base no valor da variável `temperatura`
- Exibe:
  - 🧊 “A temperatura hoje está amena” se for **menor que 30**
  - 🔥 “Hoje está fazendo calor” se for **30 ou maior**
- Permite testar o comportamento alterando o valor da variável:
  - Ex: `temperatura = 29` → saída: **"A temperatura hoje está amena"**
  - Ex: `temperatura = 31` → saída: **"Hoje está fazendo calor"**

---

### 📄 **estruturas_condicao2.py**

- Verifica o nível de conhecimento baseado na variável `tempoExperiencia`
- Utiliza operadores lógicos com `if`, `<=` e `<`
- Saídas esperadas:
  - ⏳ `tempoExperiencia < 2` → "Nível de conhecimento júnior"
  - 🧪 `tempoExperiencia` entre 2 e 5 → "Nível de conhecimento pleno"
  - 🧠 `tempoExperiencia >= 5` → "Nível de conhecimento sênior"

---

### 📄 **estruturas_repeticao1.py**

- Cria um laço de repetição `while` controlado por entrada do usuário
- Funcionalidades:
  - 🟦 Variável `entrada_idade` inicia como string vazia
  - 🌀 O loop `while` continua enquanto `entrada_idade` for diferente de `'0'`
  - ⌨️ O valor digitado é capturado com `input()` e convertido com `str()`
  - 📤 O número digitado é exibido, exceto quando for `0`
  - ⛔ Ao digitar `0`, o programa exibe: **"Programa encerrado."**

---

## 🚀 Como Executar os Arquivos

1️⃣ Tenha o **Python 3** instalado no seu computador  
2️⃣ Abra o terminal ou uma IDE como VS Code  
3️⃣ Execute os arquivos com:

```
python estruturas_condicao1.py
python estruturas_condicao2.py
python estruturas_repeticao1.py
```
